# Inter

Inter 4.1 by Rasmus Andersson, under the SIL Open Font License in `OFL.txt`.

The font file is unchanged from [Inter’s website](https://rsms.me/inter/font-files/InterVariable.woff2?v=4.1). The license comes from [the 4.1 release](https://github.com/rsms/inter/blob/v4.1/LICENSE.txt).

The toolbar and landing page call this font “Site Inter” so the page text and shared dialogs keep their current fonts.
