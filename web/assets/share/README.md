# Share and toolbar icons

These files were downloaded from the sources below and kept unchanged. No shapes or colors were drawn or edited here. The menu shows the six brand files at 16 px, with WhatsApp last.

The Share button uses the same Phosphor file on document rows and the public profile. Page styles set its size and purple color without changing the file.

The toolbar's Old ListenDock link uses Phosphor's arrow-up-right file at 16 px. It follows the menu text color, including in focus mode. The source file stays unchanged.

The blog's Back to blog link uses Phosphor's arrow-left file at 16 px. It follows the link text color. The source file stays unchanged.

The practice diagram draft uses Phosphor's microphone file for its Ask button. The source file stays unchanged.

The flow diagram draft uses Phosphor's arrow-right, arrow-down, and arrow-left files to connect its steps.

The pricing page's Continue button uses the same arrow-right file at 18 px in white. The source file stays unchanged.

The Settings checkboxes use the same check file at 14 px. The source file stays unchanged.
