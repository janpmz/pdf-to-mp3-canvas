The numbered recordings come unchanged from PDF TO MP3's `web/sample-audio/` files.
`web/canvas/example.js` pairs each recording with its text.
The example plays these files without a Gemini key or a speech request.

`ask.mp3` and `explain-*.mp3` use the words in `feature-texts.json`.
They use the Enceladus voice and tell listeners how to add their Gemini key.
`feature-manifest.json` records each clip's text, length, and file hash.
